# 连接与拓扑：实施裁决与验证边界

范围：六批路线的第一批。参考项目 RedisInsight `48ee19fab` 只读；当前项目在 `main` 上修改，不自动推送、发布、签名或安装。本文保留实施中形成的接口裁决，最终修复与验收状态以功能矩阵和测试报告为准。

## 裁决记录

按实施顺序记录；被后续裁决修正的内容同时保留，避免把中间状态误认为最终合同。

1. 按用户要求在当前分支工作，不创建 worktree。代价是没有独立工作区隔离，通过分任务提交与审查保留恢复点。
2. SSH 转发必须跟踪活动 socket 并支持取消。仅关闭 listener 不足以清理已接受连接，否则连接关闭后可能残留后台任务。
3. 新传输尚未落地的中间提交先稳定返回 `UNSUPPORTED_FEATURE`，禁止静默直连；后续实现完成后再启用合法组合。中间提交会暂时拒绝新配置。
4. 拓扑解析起初尝试以已解码值估计原始响应大小，随后明确修正：只能约束解码后的结构包络，不能恢复原始 RESP 长度。普通 Redis 传输层原始字节/分配上限未交付，服务端大响应仍可能在解析拒绝前分配内存。
5. SHARDS 默认解析优先非零普通端口，TLS 感知入口优先 TLS 端口；另一个端口仅作回退。展示 endpoint 保留公告值，实际成功连接地址单独记录；缺失或异常公告地址不能偷换成无关 seed。
6. SSH DNS 在占用 blocking permit 前超时解析，最多尝试八个地址；proxy 接收连接后才获取许可，所有 channel 循环检查取消。否则慢 DNS 或空闲 listener 会耗尽线程配额。
7. Standalone 响应超时可动态设置，Cluster 沿用 builder 的三秒上限，兼容方法不伪称可修改 Cluster 超时。自定义 multiplexed driver 由最后一个连接所有者终止；显式不验证服务器证书时保留既有不安全 TLS 语义，但仍校验握手签名。
8. 能力、profile、target、client 和 generation 来自同一活动快照。网络准备不持有代次锁，观察任务注册时检查代次；重开成功后才关闭旧 CLI 会话。旧操作可以在其捕获的旧连接完成，不能迁移到新连接。
9. 观察任务清理使用内部唯一注册身份，不能只比较用户 session ID。SSH 所有权验收也不以某个冗余字段是否存在为依据，而是验证整个已发布 handle 的有效所有权链与关闭效果。
10. Cluster 游标私有载荷可增加 pending 节点与轮转位置，保持公共 DTO 不变。只包含有界节点 ID 与数字，不包含 endpoint 或凭据；拓扑或代次变化使旧游标失效。
11. 扫描轮转顺序由游标持久保存，不受每次拓扑返回顺序影响。当前键 DTO 是 UTF-8 字符串，遇到二进制键时显式报告节点失败并保留旧游标，不能承诺所有二进制键空间都能完成遍历。
12. Cluster 分析先合并完整命名空间累加器，再裁剪 Top 15；包括最终 SCAN 页在内都遵守键数预算，聚合算术有界。Standalone 既有最后一页语义不变。
13. 实例概览仅汇总可加且完整的指标；缺节点/字段或不可加指标保持未知。数据库概览限 DB 0、primary-only，不计算无权重依据的平均 TTL；Cluster 旧单实例详情由拓扑工作区替代。
14. 显式 Agent 认证不能被遗留私钥材料改变。旧 Agent+identity 配置迁移成 PrivateKey，秘密先写、profile 后写；新保存时清除不属于所选认证方法的秘密，保留 known_hosts。
15. SSH 私钥正文/路径来源切换采用显式 clear-and-replace，拒绝双新来源与旧来源冲突。代价是清除时 known_hosts/口令也需按需重填，避免旧私钥静默覆盖新输入。
16. Cluster CLI 与 Workbench 共用发送前命令策略，拒绝事务、WATCH、协议/认证/数据库切换及订阅等 socket 状态操作。代价是这些 Cluster 会话工作流暂不支持，换取共享连接池不被事务状态污染。
17. Cluster typed Slow Log、PubSub、Profiler 暂不支持。现有 Slow Log DTO 无法表达节点来源、异构配置与部分失败；原生命令仍遵循驱动路由，不能把随机配置或混合结果宣称为全局结果。
18. typed 节点作用域操作的门控直接返回同一快照建立的连接，禁止门控后再次读取活动连接。允许旧 Standalone 操作完成，但同 ID 换成 Cluster 后不能绕过限制。
19. 获取与刷新拓扑共用实时读取实现，无额外缓存语义。拓扑、分析以及最终修复中的 Cluster 扫描在返回前复核 generation，防止跨代次结果被视为当前结果。
20. 最终 SSH 修复使用真实远端截止时间与取消清理，多密钥 Agent 尝试最多 32 个身份且不重置截止预算。超过上限的身份可能无法尝试。
21. 本地 Agent IPC 是明确的剩余边界：锁定 libssh2 在 Unix 直接阻塞读取 agent fd，在 Pageant 使用同步消息，ssh2 未暴露独立中断句柄。本批不引入跨平台代理进程；本地 Agent 卡住仍可能占用线程、许可及 CLI 生命周期锁，不能宣称认证全程可超时取消。

## 不得混淆的验证结果

- 当前 macOS 本机测试与构建、隔离 Redis/Cluster 测试，与 Windows/Linux CI 配置是不同证据。
- 默认 ignored、缺环境 early-skip、未执行的真实 sshd/TLS/Redis Stack/桌面 E2E，不计为实际通过。
- 既有 Rust dead-code、jsdom navigation、历史 fixture 重复 key 警告保留记录，不描述为零告警。
- 连接与拓扑批次不代表全量对齐；Browser、Search/Vector/Workbench、分析推荐、本地产品能力与跨平台收口仍按后续路线推进。
